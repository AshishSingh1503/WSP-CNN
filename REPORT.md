# WSP-CNN: can an LLM propose useful direct weight edits to a CNN?

Status: DRAFT. Every number below is copied from a generated file in `results/tables/` (source named in each section) and regenerated by `python scripts/reproduce_tables.py` (`--check` verifies the manifest). Section 8 (ablations) is validation-only and exploratory. Test-set numbers come from the single, frozen final evaluation (see Section 7, D10). A validation gain is never reported here as a test gain.

## 1. Summary

- **Setup.** An ImageNet-pretrained AlexNet with a new 10-class head is warmed up on CIFAR-10 (arm E0, the common start; 83.93 % test accuracy, mean of 5 seeds). We asked whether an LLM (`claude-opus-5-5`) that only sees weight statistics and validation metrics can propose structured, bounded weight edits that improve it (Pure WSP, E2), and compared it with random editing, budget-matched random search, a gradient heuristic and full fine-tuning.
- **Main result: a null result.** None of the three pre-registered accuracy claims is supported (P-a E2 vs E0, P-b E2 vs E5, P-c E3 vs E7). The mean paired differences are −0.016, −0.016 and −0.050 percentage points (pp), with 95 % intervals that include zero and lie well below the 0.3 pp minimum effect.
- **Why the differences are so small.** In most runs the final state is the unedited start model. E2 ended with an edit on 1 of 5 seeds, E3 on 1, E6 on 1, E7 on 2, and E5 and E6-RS on none. Where an edit was kept, the test change was between −0.08 and +0.30 pp.
- **Positive control (P-d): not supported.** Pure WSP reached the 80 % recovery criterion on 5 of 15 injected faults (exact one-sided binomial p = 0.164 against a 0.20 null; Holm p = 0.657). All five successes were the single-bias fault F2 (5/5); the channel-level faults F1 and F3 were 0/5 each.
- **Reference.** Full fine-tuning (E1) gains +8.43 pp (95 % interval 8.17 to 8.69 over seeds) and changes essentially all 57,044,809 scalars, so the gap that edits of at most 0.1 % of the weights could address under our DSL is not reached by any edit arm.

## 2. What was tested

Pre-registered in `PROTOCOL.md` (frozen before the test set was touched; deviations D1–D10 listed in Section 7). Hypotheses H1–H4 are one-sided; H5 (budget dose-response) and RQ6 are exploratory.

| Arm | What it is | LLM | Gradients |
|---|---|---|---|
| E0 | common start, unedited | no | – |
| E1 | full fine-tuning (reference only) | no | yes (optimizer) |
| E2 | Pure WSP | yes | never |
| E3 | Hybrid WSP (E2 plus gradient diagnostics in the prompt) | yes | diagnostics given to the LLM |
| E4 | random edits matched to the seed-4 E2 edit set | no | no |
| E5 | budget-matched random search (40 candidate slots) | no | no |
| E6 / E6-RS | last-layer-only WSP / last-layer random search | yes / no | never / no |
| E7 | gradient-heuristic search | no | yes (validation loss) |

Hybrid WSP is not gradient-free: it receives gradient information. Only Pure WSP (E2, E6) never receives gradients, which is enforced structurally. Edits are JSON validated by a strict schema and applied by our own engine to a clone; candidates are accepted on `val_edit` and the final state is chosen on `val_select`. Edit budget 0.1 % of parameters (57,044 scalars), 10 iterations × 4 candidates, 5 seeds (0–4). Splits: train 45,000, val_edit 2,500, val_select 2,500, official test 10,000.

With 5 seeds the across-seed interval has 4 degrees of freedom and the Wilcoxon test cannot go below p = 0.0625; both are low-power. E7 is the only edit arm with a kept edit on more than one seed: seed 2 (4,149 scalars; 84.36 vs 84.06 for E0, +0.30 pp) and seed 3 (10 scalars; 84.04 vs 83.97, +0.07 pp), from `arm_accuracy.csv`. No claim about E7 vs E0 was pre-registered and no interval is computed for it.

|---|---|---|---|---|---|
| F1 negate `features.10` | 28.23 | 0.50 | 0/5 | 0.09 | 0.25 |

| F3 zero `features.3` | 9.73 | 0.31 | 0/5 | 0.09 | 0.37 |

Pure WSP clearly beat the random-search and gradient-heuristic controls on F1 and F2 and was slightly below the gradient heuristic on F3 (0.31 vs 0.37). ## 4. What did NOT work

1. **LLM-proposed edits did not improve the common start** (H1 not supported). On four of five seeds the best state on `val_select` was the unedited model.
2. **Pure WSP did not beat random search** (H2 not supported). E5 also found nothing, so the two arms are tied by non-improvement, not by equal useful edits.
3. **Gradient diagnostics did not help the LLM** (H3 not supported): E3 − E7 = −0.05 pp.
4. **Fault repair did not reach the 0.20 repair-rate bar with significance** (H4 not supported), and failed entirely on the two channel-level faults.
5. **Random edits are harmful**: E4 loses 1.07 pp on average relative to E0.
6. **Edits within this DSL and budget do not approach fine-tuning** (E1 +8.43 pp).

## 5. How to read the null result

The pre-registration (Section 15 of `PROTOCOL.md`) already flagged that the E0 deficit is a diffuse shift (head-only warm-up of a frozen backbone), not a localized fault, so a null result on P-a to P-c may reflect this mismatch rather than a general failure of weight-space editing. The positive control is consistent with that reading: success on a one-scalar fault, failure on channel-level faults. These data cannot separate the mismatch explanation from limits of the DSL bounds, the prompt, or the model; neither was tested.

## 6. Limitations

- Five seeds; one LLM run per arm and seed; the LLM cannot be sampled deterministically (temperature is not accepted by the API, D5).
- The bootstrap is conditional on the five trained checkpoints; the 4-of-5 seed rule partly compensates.
- Positive-control runs share one LLM and fault family, so the 15 runs are not truly independent (optimistic for P-d).
- E4 borrows one edit set (seed 4, the only E2 edit) for all seeds, and E5 and E6-RS had 1 run per seed instead of 5 (D9), so the random baselines are weaker than planned.
- CIFAR-10 images are resized to 224×224; results are specific to AlexNet and this prompt, DSL and budget.
- The warm-up recipe and E1 tuning used `val_select` (D1–D3); no edit arm used it except to pick the final state among accepted states.
